Para que servem essas tags?

Header:

serve para criar o cabeçalho de uma página web ou de uma seção específica, ajudando a organizar o site com elementos como o logotipo, o menu de navegação e títulos

Main:

serve para marcar e isolar o conteúdo principal de uma página ou aplicativo web

Nav:

serve para criar uma seção de uma página dedicada a links de navegação

Section:

serve para agrupar conteúdos temáticos relacionados que compartilham um mesmo assunto em um documento HTML

Article:

serve para marcar um conteúdo que faz sentido por si só e é independente

Aside:

em HTML serve para marcar uma seção de página com conteúdo secundário ou que tem uma relação indireta (tangencial) com o assunto principal do site

Figure:

serve para agrupar um conteúdo visual ou autossuficiente (como uma foto, diagrama, gráfico ou trecho de código)

Footer:

para criar o rodapé de uma página web ou de uma seção específica dentro dela, indicando de forma semântica informações finais de encerramento, autoria ou links de apoio
